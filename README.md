# GuZhenRen / 蛊真人

> **以蛊炼道，以身问长生。**

`GuZhenRen` 是一个面向《杀戮尖塔 2》的自定义角色 Mod。玩家将操使蛊虫、提升转数、经营空窍，并通过道痕、合炼、杀招与虚影构筑自己的修行体系。

本项目为非官方同人 Mod，目前主要适配游戏 **0.110.0**。

## 角色特色

### 蛊虫转数

蛊虫牌拥有独立于普通卡牌升级的 **转数**，当前实现范围为一转至九转。

- 一至五转主要强化基础数值。
- 六转及以上进入仙蛊阶段，并获得额外机制。
- 转数会随卡牌保存、复制、读档及多人运行快照同步。
- 同名仙蛊具有全局唯一性：整局游戏中，所有玩家的永久牌组里最多只能存在一张同名仙蛊。

普通的 `+` 升级与蛊虫升转是两套相互独立的成长系统。

### 空窍与修为

角色的起始遗物 **空窍** 记录玩家的修为和当前转数。

战斗胜利后获得修为：

| 战斗类型 | 修为 |
| --- | ---: |
| 普通战斗 | 1 |
| 精英战斗 | 3 |
| 首领战斗 | 5 |

当前成长规则：

| 当前转数 | 突破所需修为 |
| --- | ---: |
| 一转 | 1 |
| 二转 | 2 |
| 三转 | 3 |
| 四转 | 4 |
| 五转 | 5 |
| 六转 | 2 |
| 七转 | 2 |
| 八转 | 3 |
| 九转 | 当前上限 |

其他效果：

- 二至五转时，每场战斗首张转数低于空窍的蛊虫牌可免费打出。
- 突破时会自动提升牌组中本命蛊的转数。
- 六转起，突破会结算对应的最大生命奖励。
- 六转及以上，每场战斗开始时会获得与当前转数对应的仙元牌。
- 九转是当前版本的修行上限。

### 仙元

六转后，空窍会在每场战斗第一次抽取初始手牌前生成一张仙元牌：

| 空窍转数 | 仙元牌 | 效果 |
| --- | --- | --- |
| 六转 | 青提仙元 | 获得 2 点能量 |
| 七转 | 红枣仙元 | 获得 3 点能量 |
| 八转 | 白荔仙元 | 获得 4 点能量 |
| 九转 | 黄杏仙元 | 获得 5 点能量，并抽牌直到手牌达到当前上限 |

仙元牌均为 0 费、保留、消耗，并且不会进入普通卡牌奖励。

### 升炼

篝火新增 **升炼** 选项：

- 选择一至两张尚未达到九转的蛊牌。
- 每张所选蛊牌提升一转。
- 每个休息点只能成功升炼一次。

### 合炼

篝火新增 **合炼** 选项：

- 选择符合配方的蛊虫牌作为材料。
- 配方按材料类型和数量匹配，选择顺序不影响合炼结果。
- 只有完整匹配配方时才会消耗材料并获得结果。
- 失败不会消耗材料，也不会浪费本次合炼机会。

当前实装合炼配方：

```text
月光蛊 + 小光蛊 + 小光蛊
→ 月芒蛊
```

合炼结果会继承全部材料中的最高转数。

### 杀招推演

角色的特殊起始牌 **杀招推演** 允许玩家按顺序选择手中的蛊虫牌：

- 配方匹配：消耗材料并获得对应杀招。
- 配方错误但能量足够：支付材料费用，并按选择顺序自动打出材料。
- 配方错误且能量不足：材料保留，玩家受到无法被格挡的反噬伤害。
- 杀招推演具有固有、保留和永恒，并在打出后返回手牌。
- 每存在一张杀招推演，就会额外增加一个有效手牌位置。

当前实装杀招配方：

```text
月光蛊 → 玉皮蛊
→ 月霓裳
```

杀招配方是 **有序配方**，材料顺序不同会被视为不同组合。

### 虚影

虚影无法由玩家手动打出，会在满足条件时自动触发。

当前实装的 **飞熊虚影**：

- 打出一张非虚影攻击牌时，有基础概率自动触发。
- 对所有敌人造成伤害。
- 力量对其伤害提供额外倍率。
- 运道道痕可以提高概率类卡牌的触发率。

### 道痕体系

项目内已建立十九种流派标签与对应道痕能力：

```text
光道、炎道、力道、金道、偷道、木道、食道、杀道、骨道、
律道、智道、变化道、阴阳道、剑道、血道、运道、风道、宙道、土道
```

不同道痕会提供伤害、格挡、治疗、金币、状态、保留、概率等不同方向的增益，并在回合开始时回归变化道道痕，形成动态转换体系。

## 当前卡牌内容

当前源码注册了 13 个具体卡牌模型，包括普通蛊虫、合炼结果、杀招、虚影和仙元。

| 分类 | 卡牌 |
| --- | --- |
| 起始/普通蛊虫 | 月光蛊、玉皮蛊、小光蛊、白豕蛊 |
| 特殊起始牌 | 杀招推演 |
| 稀有蛊虫 | 飞熊之力蛊 |
| 合炼结果 | 月芒蛊 |
| 杀招 | 月霓裳 |
| 虚影 | 飞熊虚影 |
| 仙元 | 青提仙元、红枣仙元、白荔仙元、黄杏仙元 |

### 部分卡牌机制

- **月光蛊**：造成伤害；高转时获得闪耀。
- **玉皮蛊**：获得格挡；六转起提供壁垒效果。
- **小光蛊**：施加虚弱并获得闪耀。
- **白豕蛊**：获得临时敏捷；六转起可跨回合保留防御。
- **月芒蛊**：合炼获得的光道攻击牌，可强化闪耀的持续使用次数。
- **月霓裳**：同时造成伤害并获得防御；六转起获得闪耀并保留剩余防御。
- **飞熊之力蛊**：对所有敌人造成伤害、施加易伤，并生成飞熊虚影。

## 多人支持

本项目包含针对多人运行的状态隔离与确定性处理：

- 空窍数据按玩家保存和同步。
- 蛊虫转数、仙元发放及战斗内一次性状态支持快照恢复。
- 合炼、升炼和唯一仙蛊规则按玩家/运行状态处理。
- 篝火选择按玩家串行执行，避免重复包或快速点击造成重复结算。
- 随机效果使用游戏/RitsuLib 的同步随机源，避免本地随机数导致客户端分歧。
- 断线重连时会恢复尚未完成的突破和仙元发放事务。

多人代码已经进行静态兼容与确定性审计，但正式发布前仍建议进行双客户端完整回归测试。

## 安装

### 前置条件

1. 《杀戮尖塔 2》`0.110.0`
2. 与该游戏版本兼容的 `RitsuLib 0.5.2` 或更新版本
3. 本 Mod 的发布文件：
   - `GuZhenRen.dll`
   - `GuZhenRen.pck`
   - `GuZhenRen.json`

### 安装步骤

将发布文件放入游戏目录下的 Mod 文件夹：

```text
Slay the Spire 2/
└─ mods/
   └─ GuZhenRen/
      ├─ GuZhenRen.dll
      ├─ GuZhenRen.pck
      └─ GuZhenRen.json
```

同时确保 RitsuLib 已按照其说明正确安装。

游戏更新可能改变 API。若游戏版本不是 `0.110.0`，请先确认本 Mod 和 RitsuLib 是否已经适配。

## 从源码构建

### 开发环境

- Windows
- .NET 9 SDK
- Godot 4.5.1 .NET/Mono
- 《杀戮尖塔 2》本地安装
- Git（可选）

### 1. 配置本地路径

复制模板：

```powershell
Copy-Item .\local.props.template .\local.props
```

编辑 `local.props`，填写本机路径。示例：

```xml
<Project>
  <PropertyGroup>
    <Sts2Dir>E:\SteamLibrary\steamapps\common\Slay the Spire 2</Sts2Dir>
    <Sts2DataDir>$(Sts2Dir)\data_sts2_windows_x86_64</Sts2DataDir>
    <GodotExe>C:\path\to\Godot_v4.5.1-stable_mono_win64.exe</GodotExe>
  </PropertyGroup>
</Project>
```

`local.props` 包含本机路径，不应提交到 Git。

### 2. 还原并构建

```powershell
dotnet restore
dotnet build
```

默认构建会：

1. 编译 `GuZhenRen.dll`
2. 将 DLL 和 `GuZhenRen.json` 复制到游戏的 Mod 目录
3. 通过 Godot 导出 `GuZhenRen.pck`

仅检查 C# 编译、不导出 PCK：

```powershell
dotnet build -p:RunPckExport=false
```

不复制文件到游戏目录：

```powershell
dotnet build -p:RunPckExport=false -p:CopyModOnBuild=false
```

### Publicizer 文件占用

若构建时报错，提示 `.godot\mono\temp\obj\...\PublicizedAssemblies\sts2.dll` 正被其他进程使用，可先关闭 Godot 和游戏，再执行：

```powershell
dotnet build-server shutdown

Get-Process |
    Where-Object {
        $_.ProcessName -match "godot|msbuild|VBCSCompiler"
    } |
    Stop-Process -Force -ErrorAction SilentlyContinue

Remove-Item .\bin, .\obj, .\.godot -Recurse -Force -ErrorAction SilentlyContinue

dotnet build `
    -m:1 `
    /nr:false `
    -p:UseSharedCompilation=false `
    -p:RunPckExport=false
```

## 开发状态与已知限制

- 当前目标版本为游戏 `0.110.0`。
- 当前最高实现至九转。
- 暂未实现灾劫和十转内容。
- 药水池结构已建立，但当前没有自定义药水内容。
- 部分资源可能仍为占位美术，详情见 `PLACEHOLDER_ASSETS.md`。
- 项目已通过本地 .NET 9 编译；发布前仍需要在真实游戏中测试完整流程。
- 游戏或 RitsuLib 更新后，Harmony 目标方法和 API 签名可能需要重新适配。

建议发布前至少测试：

1. 单人完整开局、奖励、商店、升炼、合炼、保存和读档。
2. 每种蛊虫从一转成长至六转以上时的效果变化。
3. 杀招推演的成功配方、错误配方、能量不足和取消选择。
4. 虚影触发概率、力量倍率和防递归行为。
5. 两名玩家同时使用蛊真人时的空窍、篝火和唯一仙蛊规则。
6. 断线重连后的修为、仙元、升转和牌组状态。
